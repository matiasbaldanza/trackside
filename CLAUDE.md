# CLAUDE.md

Instructions for this repository live in **[AGENTS.md](./AGENTS.md)**. Read it before making
changes.

It is the canonical file and is deliberately not duplicated here — two copies of the same
instructions drift, and a reader cannot tell which one is authoritative.

Points that are easiest to get wrong, as a pointer to the relevant sections:

- **pnpm only.** Never npm or yarn.
- **Never describe this project as a demo, sample, or time-boxed exercise**, and never justify a
  decision by schedule pressure. See *Documentation tone* in AGENTS.md.
- **No `Co-authored-by` trailers** on commits.
- **Write the ADR when the decision is made**, not afterwards.
- **Never claim a check passed unless it actually ran.**
